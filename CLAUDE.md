# Agent instructions

- `site/` is generated by `tools/build-site.mjs` from the guide master (the claude.ai artifact) and `game/gridrunner.html`.
  Never edit `site/` by hand. Build and deploy steps are in `README.md`.
- OpenText World kiosk mode is archived and switched off (`KIOSK_ON=false` in the master and in `game/gridrunner.html`).
  Before changing anything kiosk-related, or when preparing OpenText World 2027, read `archive/otw-2026-kiosk/README.md`.
  It maps the kiosk code and gives the revival steps.
- Do not delete kiosk code from the master; it is kept for reuse.
